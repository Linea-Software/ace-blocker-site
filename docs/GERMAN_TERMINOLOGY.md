# German Localization (de-DE): Terminology and Editorial Rules

Reviewed November 6, 2026. Source: `messages/en.json`. Consult Italian only to clarify meaning.

| Product term (EN) | Preferred German form | Meaning and use |
| --- | --- | --- |
| Network Block            | **Netzwerksperre**                                      | Website and category rules with a schedule. Examples: „Netzwerksperre erstellen“, „Diese Netzwerksperre greift gerade“. |
| Lock / time lock         | **Änderungsschutz**; **zeitgebundener Änderungsschutz** | Prevents weakening Network Block or Resistance settings. Does **not** add blocked sites. Examples: „Änderungsschutz einrichten“, „Schutzfrist verlängern“. |
| Reflection Lock          | **Reflexionsschutz**                                    | Protection with a question and five-minute wait. Example: „Reflexionsschutz aktivieren“. |
| Schedule                 | **Zeitplan**; **Sperrzeiten**                           | Specifies rule activation periods. „Immer“ means continuous. Use „Montag–Freitag“, not ambiguous „werktags“. Example: „Zeitplan festlegen“. |
| Resistance Mode          | **Widerstandsmodus**; kurz **Widerstand**               | Changes feeds, colors, and videos without blocking a whole website. Example: „Widerstandsmodus aktivieren“. |
| Resistance interventions | **gezielte Eingriffe**                                  | Five groups: feeds, videos, visual stimuli, delays, and simulated CAPTCHA. No intensity levels. |
| Categories / Site Packs  | **Kategorien**; für technische Pakete **Listenpakete**  | Preselected sites. Downloading a list does not activate a block. Assign it to a Network Block. |
| Custom Lists             | **eigene Listen**                                       | Imported domains. Example: „Eigene Liste importieren“. |
| Free / Pro               | **Free / Pro**                                          | Keep plan names unchanged. Descriptions may use „kostenloser Tarif“ and „Pro-Tarif“. |

## Language Rules

- Use standard German for Germany. Address users as `du/dein`, not `Sie`.
- Keep actions short. Explain security and cancellation effects clearly.
- Do not use „Block“ for both a Network Block and an edit lock.
- Use „Widerstand“ in narrow UI controls when „Widerstandsmodus“ does not fit.
- Follow the English source. Consult Italian only when meaning is unclear.
- Preserve placeholders. Check agreement for zero, one, and multiple items.

## Publication Review

Privacy and Terms translations keep the meaning of the English source. They are **not legal reviews**.
Before publication in Germany, obtain qualified review of data collection and encryption claims.
Also review withdrawal, refunds, liability limits, age limits, and subscription renewals.
Verify English claims against real product behavior before publication.
